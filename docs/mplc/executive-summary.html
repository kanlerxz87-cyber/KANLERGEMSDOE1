The gates a file must pass before step 1 (all automated, no human inspector)

  1. Format/range: vendor gems57.validate — single band, float32, 3730×3292, EPSG:32611, exact sample-submission transform, no NaN/Inf anywhere, every value in [0,1] (all-finite build; this prevents the portal error “Predicted values must be in range [0, 1]”), 0 outside the footprint, 0 dots on the mapped catalogue.
  2. Leakage canary: every new feature alone AUC ≤ 0.90 (two-sided) on withheld positives.
  3. Holdout efficacy: pooled HOLDOUT-DTI beats the same-evaluator control with paired spatial-block 95% CI > 0, and does not regress on the off-catalogue SGMC discovery proxy vs the champion.
  4. Uniqueness: pre-placement surface |Spearman| ≤ 0.90 and final-dot 3-px overlap ≤ 70% vs every discrete registry raster (spacing-5 lattice blanket disclosed separately, IR-K1).
  5. Selector approval: a separate step checks the weekly cap on the submission page. This repo never contacts DrivenData.

Submission procedure (for a future approved file)

  1. Download the approved .tif (or its single-TIF .zip) from the home page; verify its SHA-256 against the run card.
  2. Go to DrivenData competition #306 → New submission.
  3. File to submit: choose the downloaded .tif (single-band GeoTIFF; CRS/shape/geotransform already match the sample submission).
  4. Note (optional, ≤140 chars in our convention): paste the note from the run card, e.g. a future approved note would name the method, dot count, and HOLDOUT-DTI — never a projected live score.
  5. Check your remaining weekly submissions on the page, then Create submission.
  6. Save the submission-page receipt (score + submission ID) into evidence/ — only then may a score be labelled ORGANIZER-CONFIRMED and tied to those exact bytes.

Evidence classes used everywhere in this project

  • HOLDOUT-DTI — local hide-and-recover measurement (evaluator version, withheld n, 95% CI always attached). Never a leaderboard score.
  • OWNER-REPORTED — a score claimed in a prompt/site with no organizer receipt (all 9 focus-site scores, including 0.2778).
  • ORGANIZER-CONFIRMED — copied from a submission-page receipt tied to exact bytes. None exists in this repo.
  • PROJECTION — a model-based forecast. We publish none: no calibrated holdout→live mapping exists (README §Score estimation).
