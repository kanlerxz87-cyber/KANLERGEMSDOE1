1. The metric, from the official page

From DrivenData page 967:

k(d) = max(1 − d/R, 0), R = 300 m = 3 px
TP_w = Σ_g max_{x: d(x,g)≤R} p(x) k(d(x,g))
FP_w = Σ_{x: p(x)>0} p(x) [1 − max_g k(d(x,g))]
FN_w = Σ_g [1 − max_x p(x) k] = |G| − TP_w
DTI(0.2, 0.8) = TP_w / (TP_w + 0.2 FP_w + 0.8 FN_w)

Known USGS/INGENIOUS faults are excluded from evaluation (organizer forum thread 11516, cited across GEMSDOE repos). Training on the public catalogue and emitting a halo around it is therefore a false-positive factory.

3. Can we score higher than 0.2778?

Yes in principle, no with this session’s unique rasters.

  • The public leaderboard is already at 0.4437. The GEMSDOE family is not the global ceiling.
  • Beating 0.2778 with a unique file requires a ranking field whose high-credit pixels are not the same scarp pixels H19-5 already found, packed with similar metric hygiene (sparse, off-catalogue, ~300 m spacing).
  • This session’s IEDR/HTSI fields are unique (18.9% / 18.7% 3-px overlap vs champion) and slightly above champion on HIDE-RECOVER-v3.0 point estimates (0.00617 / 0.00628 vs 0.00452) with overlapping 95% CIs, and they lose badly on off-catalogue SGMC (0.034 / 0.030 vs 0.096). That is not a promote.
  • Hide-and-recover of mapped scarps is a biased proxy for blind geothermal faults. A method that is right for the private test set can look worse on this holdout. We still will not spend a slot without a holdout win, because the alternative is lottery tickets.
