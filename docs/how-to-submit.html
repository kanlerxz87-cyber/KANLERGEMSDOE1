When a candidate is eventually promoted

  1. On this site's executive summary, verify the current banner explicitly says OK TO SUBMIT, and the selected candidate's run card says "verdict": "promote" and "ok_to_submit": true. A format pass alone is not promotion.
  2. Use only the exact single-band GeoTIFF (or ZIP containing exactly one GeoTIFF) specified in that promotion record. Confirm it matches the official sample's CRS, dimensions, and affine transform. Do not use a similarly named diagnostic TIFF.
  3. Before upload, ensure every prediction value within the valid footprint is finite and in [0,1]. NaN, infinity, nodata sentinels, logits, and values outside that interval inside the footprint can trigger Predicted values must be in range [0, 1]. The shared writer rejects invalid inputs rather than silently clipping them.
  4. Respect the sample's outside-footprint representation and the competition's format instructions. This repo emits a NaN-outside candidate ZIP and a zero-outside diagnostic TIFF; they are not interchangeable. Local validation is not proof of DrivenData acceptance, and no candidate here has a portal receipt.
  5. Only after the separate team selector approves a slot, open the official competition submission page, choose New submission, attach that exact file, and enter the run-card note (maximum 140 characters). Keep the submission receipt; only it can support an ORGANIZER-CONFIRMED score claim.
