3. Why GEMSDOE32 scored 0.2778 (what we verified)

  1. Lineage (verified by file): the GEMSDOE32 file is the H19-5 surface (121,131 px) after raster-order Euclidean thinning at spacing √8 px (44,090 px), then removal of dots within 2 px of mapped faults (37,654 px). The shared reimplementation of the thinning matches the owner's d2.8 layout to within 181 px (100% of owner pixels within 3 px).
  2. Metric reason: the official distance-weighted Tversky index with α = 0.2, β = 0.8 gives DTI = TP / (0.2·(TP+FP) + 0.8·|G|). Missed truth (FN) dominates, so coverage is cheap, while false positives cost only 0.2 each. Thinning removes redundant dots that add FP without adding max-credit, and the collar removes dots sitting on digitization halos of mapped faults.
  3. Experiment X1 (1 of 3 budget): on the same surface, the holdout is best at the 2.83 px spacing among the arms tested. Sparser spacing lowers the surrogate, and so does the denser owner d1.5 layout. This is a negative result for spacing as a lever.
  4. Caveat: the holdout surrogate does not rank organizer scores reliably (IR-03), and the random-placement canary scores 0.047 (IR-04). Neither proves that 0.2778 is the best achievable.
