Hashes prove mirror consistency only. Please compare the SHA-256 values against your own authenticated DrivenData download before relying on any local number.
  3. Uniqueness rule is saturated by the r13-lattice-s5_v2 reference. Its 3-px footprint coverage is 99.87%, so a dot inside the footprint is within 3 px of it almost by chance. Under the literal rule every candidate fails against it, including all earlier candidates. We therefore report a literal result and a detector-only result that excludes references covering at least 70% of the footprint. This exclusion is our own decision, not an official rule (the official page gives only the metric and format). Decision needed from the team.
  4. Holdout proxies disagree. The fold-local HIDE-RECOVER score for this file is 0.0648, below the champion's repo-reported 0.099202, while SGMC-CAL is 0.0892 (above the champion's 0.064121). The HIDE-RECOVER task recovers catalogue faults, which the official scorer masks out (staff reply, link above), so SGMC is the closer analogue. This is a reasoned choice, not a verified result.
