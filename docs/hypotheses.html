Stack-only		 Conductive-base step geometry × geodetic dilation
Surface conductivity; depth to conductive base surface; dilatation rate; shear strain rate; second strain invariant.		 Test persistent, multi-scale discontinuities/step-overs in conductive-base depth and conductivity where geodetic dilation or shear localization supports an opening/shear corridor. The geophysical/strain evidence is independent of proximity to visible fault lines, so it can nominate a buried or unmapped segment if the structural signal exists. This is a physically motivated prior, not a result: a USGS study of Great Basin hydrothermal systems reports localized stress/strain at structural discontinuities, especially fault stepovers and terminations. The feature transformation is a cross-layer geometric interaction, not label-conditioned dot thinning or a terrain-only scarp detector. However, published sites discuss clay-cap, conductivity, and structural-conduit ideas; global novelty is not cleared. Sedimentary-basin boundary, lithologic contact, conductive clay alteration without a fault, saturated basin fill, or interpolation seam. Relative potential: highest of this slate, but unknown. Cost: medium; all named layers are in the official provided-feature description, but files are login-gated here.
2
External data		 Effort-adjusted shallow-temperature residual × strain
DOE GDR INGENIOUS 2-meter temperature-probe observations; competition dilatation/shear layers.		 After spatially blocked background correction using only metadata-supported covariates, test whether local shallow thermal residuals align with strain corridors away from visible faults. DOE GDR 1391 lists a Great Basin 2-m probe resource; a separate GDR 2-m survey method record describes its use to investigate possible upflow structures and explicitly warns that measured temperatures also vary with solar heating. A thermal upflow can reveal fluid ascent associated with a previously unmapped conduit, but the competition labels are faults, not geothermal sites; spatial linkage must be demonstrated. Adds a sparse, independent observation family not listed among the competition's raster feature layers. This is distinct from using only the competition's conductivity/gravity/terrain stack. A historical GEMSDOE24 page names a geothermal-lineament experiment, so full prior-art review is required. Solar exposure/aspect, elevation, soil moisture, shallow groundwater, seasonal/campaign effects, land-cover differences, or biased probe placement. Relative potential:Cost: high because sparse sampling, provenance, effort bias, coordinate alignment, and cross-validation must be handled. DOE GDR lists a public 2-m probe ZIP under CC BY 4.0; live file transfer was not tested here.
3
Stack-only		 Magnetic source-depth edge persistence × gravity-edge concordance
Top-of-crustal magnetic source-depth estimate; RTP/TMI anomaly gradients; isostatic gravity anomaly and its slope.		 Look for linearly persistent, multi-scale offsets in inferred magnetic source depth that are independently supported by a gravity gradient. Buried basement discontinuities may survive where the surface has no clear scarp and the visible catalogue is incomplete. An official USGS potential-field case study reports springs near local breaks and bends in a magnetic anomaly; that is a site-specific analogue, not proof that the same signature predicts the competition faults. Uses co-registered cross-physics edge persistence rather than a single magnetic edge or binary point-density mask. Prior-art risk is high: source sites already describe pseudogravity, magnetic curvature, and potential-field dipole approaches, so novelty must be established from code and raster registry. Intrusive bodies, lithologic boundaries, alteration fronts, flight-line artifacts, or unrelated density/susceptibility contrasts. Relative potential:Cost:

Confounded		 Earthquake-density anisotropy × strain-gradient interaction
Earthquake density; shear strain rate; dilatation; second strain invariant.		 Test directional persistence in the earthquake-density surface where strain gradients independently support a corridor, while excluding the visible fault mask. An active, unmapped fault may localize seismicity and deformation even without a mapped trace. Uses density-gradient orientation and fold-local interaction rather than treating earthquake density as a generic scalar feature. The official stack already includes earthquake density, and external site histories are extensive, so this is least likely to be globally novel. Viability and validation

What has to happen before the top candidate is tested

Lane blocker

One method paragraph is missing

The parallel protocol says the session must stay inside a single method lane, but the prompt contains no unambiguous lane paragraph. The hypothesis ranking is not a license to test all four.

Data blocker

Competition assets are absent

Download the authenticated official data to the designated data folder, then verify it against the official sample submission and shared template. The login redirect was observed; no data bytes were fetched.

Prior-art blocker

External experiment history is incomplete

Audit the pinned source code, manifests, and raster hashes across all nine specified sites before calling any method globally novel. Public landing pages alone cannot prove a method was never tried.

Preflight for candidate 1: only if an active lane is formally identified and the shared tools/data are restored, preregister the edge scales and directional interaction, define the non-fault controls, freeze spatial folds, run each input feature alone through the leakage canary, and compare against the same-fold shared baseline. If the lane refers to a different mechanism, do not substitute candidate 1.

External-data availability check

The official DOE Geothermal Data Repository entry INGENIOUS — Great Basin Regional Dataset Compilation says the collection is publicly accessible under CC BY 4.0 and lists “2m Temperature Probes.zip” as a downloadable resource. The page lists the resource; this sandbox did not retrieve or hash the ZIP. The competition permits additional data only when the license permits use for the challenge and sharing with the sponsor. Check the dataset's terms, metadata, spatial coverage, campaign dates, and covariates before treating candidate 2 as viable.
