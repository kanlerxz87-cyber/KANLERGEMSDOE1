What this lane is

H1 IEDR (selected method). Rank pixels by independent-earthquake density ridges (INGENIOUS ieq_n100a15, band 16) × geodetic dilatation (band 8) × TMI horizontal gradient (band 3), then emit 32,000 unit dots with field-ranked Poisson disk at min distance √10 px (316 m) and a 2-pixel catalogue collar. This is not a re-thin of H19-5 / H33-2-B2 (those use raster-order D2.8 = √8 px on a scarp surface).

Limitations (this sandbox)

  • No DrivenData login — competition rasters were restored from SHA-256-pinned GitHub mirrors (integrity-pinned, not organizer-authenticated). See sources.
  • Hide-and-recover uses withheld mapped faults, which are biased toward exposed scarps. Blind geothermal faults can look worse on this proxy than they would on the private test set.
  • A HOLDOUT-DTI is not a leaderboard score. Protocol forbids writing projections as scores.
  • The 5-px calibration lattice overlaps ~99% of any dense-enough dot map (IR-42-UNIQ-01). Uniqueness is judged against genuine detector rasters, with lattice reported separately.
