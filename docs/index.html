Decision path

Three things must be true before any TIFF is uploadable

File format, scientific evidence, and global uniqueness are separate gates. Passing one does not substitute for another.

Gate 01 · scientific

Beat a matched holdout

Use buffered whole-segment hide-and-recover with visible-only catalogue features, exact masking, leakage canaries, and the shared DTI evaluator. Report evaluator, withheld positives, and 95% CI.

Gate 02 · uniqueness

Stay outside every duplicate lane

Check the pre-placement surface and final dots against the full registry. Stop at absolute rank correlation above 0.90 or more than 70% of dots within 3 pixels of one raster.

Gate 03 · file

Validate the saved GeoTIFF

Match the sample template's CRS, shape, bounds, resolution, and transform; require one float32 band, in-footprint values in [0,1], and null/NaN outside bounds as specified.

Next research step

Use the science, not the filename

The candidate slate is intentionally qualitative. It contains no score projections and is not a claim of global novelty.

First-ranked proposal: test whether discontinuities in the conductive-base-depth/surface-conductivity layers become more informative when conditioned on local geodetic dilation and shear. The signal could expose buried fault structure, but basin edges, lithologic contacts, clay alteration, and saturation are realistic mimics. It cannot be run until data, shared tools, full registry, and a lane are present.
