What this project does

Builds and audits geological feature surfaces for DOE GEMS; evaluates candidates with spatially blocked, fold-local hide-and-recover tests; checks feature leakage; compares candidate surfaces and final dots against a registry; validates GeoTIFF structure and values; and publishes a traceable decision. Historic peer results are for learning and are not authorization to reuse another team's file.
